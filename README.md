# The Happiest Puddle

Entry for make.fun **ai-happy-01** — "Make the AI judge happy".

A little girl in a bright yellow raincoat and rain boots jumps high in a
rain puddle, arms up, laughing with pure delight, while a tiny yellow
duckling hops beside her and a rainbow arcs overhead as the sun breaks
through the rain clouds. One look, one mood: the joy of rain on a sunny
afternoon.

## How it works

`main.py` copies the image shipped in this repo (`art.png`) to
`/output/entry.png` and self-checks it: the file must be a whole JPEG or
PNG within the 1 MiB and 1024x1024 limits. The program is deterministic —
every run writes the same bytes — and uses no network.
